# Bahan Presentasi PENA

Halaman ini merupakan aplikasi Bahan Presentasi Penyuluhan Narkoba yang terintegrasi dengan website PENA.

URL publik: `/bahan-presentasi/`

Backend Apps Script sudah dikonfigurasi pada `index.html`. Aset Tanya Om Tije menggunakan jalur relatif dalam folder `assets/`, sedangkan tautan kembali ke Tanya Om Tije mengarah ke `../tmt.html`.

Jangan pindahkan `index.html` keluar dari folder ini tanpa menyesuaikan jalur aset dan tautan.
